Detailed Description

Networking.

Methods for TCP and UDP connections using libclod's stream API. IPv4 is also supported - just use an IPv4-mapped IPv6 address; bytes 0-10 = 0, byte 11 = 0xFF, bytes 12-15 = IPv4 address.
